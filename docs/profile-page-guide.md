# 개인 프로필 페이지 기획 및 개발 가이드

## 1. 프로젝트 개요

HTML, CSS, JavaScript를 사용해 자신을 소개하는 반응형 개인 프로필 웹페이지를 만든다.

### 목표

- 방문자가 프로필 주인에 관한 핵심 정보를 쉽게 확인할 수 있게 한다.
- 모바일, 태블릿, 데스크톱에서 자연스럽게 보이도록 구현한다.
- 시맨틱 HTML과 접근성을 고려한다.
- JavaScript로 간단한 사용자 상호작용을 제공한다.

## 2. 주요 사용자

- 프로필 주인에 대해 알고 싶은 방문자
- 프로젝트와 기술 역량을 확인하려는 채용 담당자 또는 협업자
- 이메일이나 SNS를 통해 연락하려는 사용자

## 3. 페이지 구성

### 헤더와 내비게이션

- 이름 또는 로고
- 소개, 기술, 프로젝트, 연락처 영역으로 이동하는 메뉴
- 모바일 화면용 메뉴 버튼

### 메인 프로필 영역

- 프로필 이미지
- 이름과 직무 또는 관심 분야
- 짧은 소개 문구
- 이력서 보기 또는 연락하기 버튼

### 자기소개 영역

- 상세 소개
- 관심 분야와 목표
- 거주 지역 등 공개 가능한 기본 정보

### 기술 영역

- HTML
- CSS
- JavaScript
- 그 밖의 사용 가능한 도구 또는 기술

기술은 카드, 태그 또는 숙련도 형태로 표현한다. 숙련도를 수치로 표시할 경우 객관적으로 설명할 수 있는 기준을 함께 둔다.

### 프로젝트 영역

각 프로젝트 카드에는 다음 정보를 표시한다.

- 대표 이미지
- 프로젝트 이름
- 간단한 설명
- 사용 기술
- 데모 링크
- 소스 코드 링크

### 연락처 영역

- 이메일
- GitHub 및 기타 SNS 링크
- 이름, 이메일, 메시지를 입력하는 연락 폼(선택 사항)

### 푸터

- 저작권 문구
- 상단으로 이동 버튼

## 4. 권장 파일 구조

```text
frontend/

├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    │   ├── profile.jpg
    │   └── projects/
    └── icons/
```

## 5. 기술별 역할

### HTML

- `header`, `nav`, `main`, `section`, `article`, `footer` 등 의미가 분명한 요소를 사용한다.
- 페이지 제목은 하나의 `h1`로 작성하고 하위 제목은 순서에 맞게 배치한다.
- 이미지에는 내용을 설명하는 `alt` 속성을 작성한다.
- 메뉴와 버튼에는 목적을 이해할 수 있는 텍스트를 사용한다.

### CSS

- 색상, 간격, 글꼴을 CSS 변수로 관리한다.
- Flexbox와 Grid를 사용해 레이아웃을 구성한다.
- 모바일 화면을 우선으로 작성한 뒤 미디어 쿼리로 넓은 화면을 지원한다.
- 키보드 사용자를 위해 `:focus-visible` 스타일을 제공한다.
- 지나친 애니메이션을 피하고 `prefers-reduced-motion` 설정을 고려한다.

### JavaScript

- 모바일 내비게이션 열기와 닫기
- 메뉴 선택 시 해당 영역으로 이동
- 다크 모드 전환 및 선택 값 저장(선택 사항)
- 스크롤 위치에 따른 메뉴 활성화(선택 사항)
- 연락 폼 입력값 검사(연락 폼을 구현할 경우)

JavaScript가 비활성화되어도 기본 콘텐츠와 링크를 이용할 수 있도록 작성한다.

## 6. 디자인 기준

### 색상 예시

```css
:root {
  --color-primary: #4f46e5;
  --color-text: #1f2937;
  --color-muted: #6b7280;
  --color-background: #ffffff;
  --color-surface: #f3f4f6;
}
```

색상은 변경할 수 있지만, 텍스트와 배경 사이에 충분한 대비가 있어야 한다.

### 화면 크기 기준

- 모바일: 기본 스타일
- 태블릿: `768px` 이상
- 데스크톱: `1024px` 이상

### 공통 원칙

- 본문 최대 너비를 제한해 긴 문장이 지나치게 넓어지지 않게 한다.
- 같은 종류의 카드와 버튼에는 일관된 모양과 간격을 적용한다.
- 주요 버튼과 일반 링크의 시각적 우선순위를 구분한다.

## 7. 콘텐츠 준비 목록

개발 전에 다음 내용을 준비한다.

- 표시할 이름
- 직무 또는 한 줄 소개
- 프로필 사진
- 상세 자기소개
- 보유 기술 목록
- 프로젝트별 제목, 설명, 이미지, 링크
- 공개할 이메일과 SNS 주소
- 이력서 파일 또는 링크(선택 사항)

실제 개인정보 중 주소, 전화번호 등 불필요하게 민감한 정보는 공개하지 않는다.

## 8. 구현 순서

1. 콘텐츠를 준비하고 페이지 영역을 확정한다.
2. `index.html`에 전체 구조와 내용을 작성한다.
3. `style.css`에 모바일 기준 공통 스타일을 작성한다.
4. 태블릿과 데스크톱 반응형 레이아웃을 추가한다.
5. `main.js`에 필요한 상호작용을 구현한다.
6. 키보드 조작, 이미지 대체 텍스트, 색상 대비를 점검한다.
7. Chrome, Edge, Firefox와 여러 화면 크기에서 확인한다.

## 9. 완료 기준

- 모든 메뉴가 올바른 영역으로 이동한다.
- 프로필, 소개, 기술, 프로젝트, 연락처 정보가 표시된다.
- 모바일과 데스크톱에서 콘텐츠가 잘리거나 겹치지 않는다.
- 외부 링크가 올바르게 연결된다.
- 키보드만으로 메뉴와 버튼을 사용할 수 있다.
- 개발자 도구 콘솔에 JavaScript 오류가 없다.
- 이미지 경로가 올바르고 대체 텍스트가 제공된다.
- 연락 폼이 있다면 필수 입력값과 이메일 형식을 검사한다.

## 10. 추후 확장 아이디어

- 다크 모드
- 한국어/영어 전환
- 프로젝트 필터링
- 방문 시 부드러운 등장 애니메이션
- 블로그 또는 경력 타임라인
- 백엔드와 연동한 연락 메시지 전송

초기 버전에서는 핵심 프로필 정보와 프로젝트 소개를 먼저 완성하고, 확장 기능은 기본 페이지가 안정적으로 동작한 뒤 추가한다.
